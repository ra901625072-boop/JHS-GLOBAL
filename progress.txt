# Ralph Progress & Learnings Ledger
Project: JHS GLOBAL B2B Export Platform
Target: 4-Category Expansion, 96 New Catalogue Products, Messaging Alignment, FIEO Badge

## Codebase Patterns & Architectural Invariants
- Stack: React + Vite + Tailwind, TanStack Query v5, Express REST API (/api/v1), PostgreSQL 16+ via Sequelize, Zod.
- Brand name: "JHS GLOBAL" (exact spelling). No checkout, no cart, no public pricing ("Price on request").
- Public visibility: Only products with isActive: true and isDeleted: false are queried.
- Public fields: Fields without verified sources (specs, HS codes, certificates, packing, origins, MOQ) must remain empty and cleanly hidden on the public site without displaying "TODO(client)".
- Health claims: Never output therapeutic or medicinal claims for botanical powders or herbs. Neutral food/formulation ingredients only.
- FIEO: Text badge representation only; status details marked as TODO(client) internally.
- Ports & Messaging: Replace specific port names and third-party inspection agencies with complete supply chain management, multi-category consolidation, and agreed-per-order port logistics.
- Additive migrations: Never drop existing tables or delete existing 20 products. Take pg_dump backup before database operations.
